# Conținut Sales Hub · cum editezi

Aici găsești **tot conținutul textual** care apare în dashboard, organizat pe fișiere markdown ușor de editat.

## Cum funcționează

1. **Tu editezi** fișierul .md respectiv (ex: `produse/incredere.md`)
2. **Îmi spui lui Claude** ce ai modificat: „am modificat content/produse/incredere.md, actualizează dashboard"
3. **Claude actualizează** `data.js` automat din .md-ul tău
4. Verifici dashboard-ul, dacă e ok → push pe GitHub

## Reguli simple de editare

✅ **Da:**
- Modifică textele direct
- Adaugă liste cu `-` sau `*`
- Folosește **bold** și *italic* normal
- Păstrează structura `## Titlu` și `### Subtitlu`

❌ **Nu:**
- Nu redenumi fișierele (Claude le caută după nume)
- Nu șterge headere mari (`## Beneficii`, `## Discovery` etc) — Claude le folosește ca markeri
- Nu modifica linkuri (URL-uri Vimeo, link-uri site) fără să-i spui lui Claude — trebuie actualizate și în alte locuri

## Când dai push

1. Salvezi modificările tale în .md
2. Îmi spui „actualizează dashboard din content/X.md"
3. Verifici că dashboard-ul arată cum vrei
4. „Dă push"
